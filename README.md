# Мониторинг вакансий LinkedIn → Telegram

Скрипт проверяет публичный поиск вакансий LinkedIn (без логина) по запросам из `config.json`, отсеивает уже виденные вакансии и присылает новые в Telegram.

## 1. Установка

Нужен Python 3.9+.

```
pip install requests beautifulsoup4
```

Положите `linkedin_jobs.py` и `config.json` в одну папку.

## 2. Telegram-бот

1. В Telegram напишите @BotFather → `/newbot` → получите токен вида `123456:ABC...`.
2. Напишите своему боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}` — это ваш chat_id.
4. Впишите оба значения в `config.json`.

Если токен не указан, вакансии просто печатаются в консоль.

## 3. Настройки (`config.json`)

| Поле | Что значит |
|---|---|
| `searches` | Поисковые запросы, каждый ищется отдельно |
| `location` | Локация поиска (`Worldwide`, `Europe`, `Bulgaria`…) |
| `remote_only` | `true` — только удалённые вакансии |
| `posted_within_hours` | Вакансии не старше N часов |
| `pages_per_search` | Сколько страниц (по ~10 вакансий) смотреть на запрос |
| `exclude_words` | Отбрасывать, если слово есть в названии или компании |
| `require_any_words` | Если не пусто — оставлять только вакансии с одним из слов |
| `delay_between_requests_sec` | Случайная пауза между запросами |

## 4. Первый запуск

```
python linkedin_jobs.py
```

Первый запуск пришлёт всё, что найдётся за последние сутки. Дальше — только новое. Список виденных вакансий хранится в `seen_jobs.json` рядом со скриптом (удалите его, чтобы начать с нуля).

## 5. Запуск по расписанию (например, каждые 3 часа)

**Windows** — Планировщик заданий → Создать задачу → Триггер «Ежедневно», повторять каждые 3 часа → Действие: программа `python`, аргументы `linkedin_jobs.py`, рабочая папка — папка со скриптом.

**macOS / Linux** — `crontab -e` и строка:

```
0 */3 * * * cd /путь/к/папке && /usr/bin/python3 linkedin_jobs.py >> log.txt 2>&1
```

## Если что-то сломалось

- **Ответ 429 / 999** — LinkedIn притормаживает. Запускайте реже, уменьшите число запросов или страниц, увеличьте паузы.
- **«Новых вакансий: 0» всегда** — возможно, LinkedIn поменял вёрстку карточек; тогда нужно поправить селекторы в `parse_jobs()`.
- Не запускайте чаще раза в 1–2 часа: для личного поиска этого хватает, а риск блокировки IP растёт с частотой.
